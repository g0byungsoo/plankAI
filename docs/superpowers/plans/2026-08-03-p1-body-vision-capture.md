## Batch A tasks

1. **Model + privacy plumbing (L4, one commit):** `BodyScanRecord` (id unique, userId, capturedAt, dayKey, poseQuality, renderMode "silhouette"|"photo", notes?, backedUp=false) appended to PlankSync Models.swift; registered in the app container (PlankAIApp:921 region) + TestModelContainer; delete-account purge via `BodyScanStore.deleteAll` beside `ObservationStore.deleteAll` (AppSync:1058); `"bodyScan."` joins `scopedPrefixes` (AppSync sweep) so consent/render/backup keys sweep as a family. Records survive sign-out like weight logs (userId-scoped).
2. **Stores:** `BodyScanPhotoStore` (Application Support/BodyScans, `{id}.jpg` photo long-edge 1600 q0.8 EXIF-free + `{id}.sil.png` silhouette long-edge 1200; excluded-from-backup; delete/deleteAll/rekey; `onPhotoPersisted` seam dormant for Batch B). `BodyScanStore` (@MainActor enum: insert/latest/all/count/delete/deleteAll; AppStorage keys `bodyScan.consentSeen`/`bodyScan.renderMode`/`bodyScan.backupOn`; `anchorWeekday` from latest scan; first-scan default offer day = Sunday for Batch B).
3. **AlignmentEngine (pure, tested):** normalized-joint verdicts — `searching / tooFar / tooClose / offCenter(left|right) / aligned` from bbox height band [0.60, 0.92] + centerX band [0.38, 0.62] + required joints (shoulders+hips+ankles ≥0.3 confidence); `Arming` struct state machine (N=12 consecutive aligned → .armed; any miss resets). ~10 unit tests.
4. **BodyCaptureSession:** front wide camera, `.photo` preset, AVCapturePhotoOutput (mirrored still, resume-once continuation, freeze frame) + AVCaptureVideoDataOutput pose stream (every 3rd frame, VNDetectHumanBodyPose, 14 joints normalized, published @MainActor). Start/stop lifecycle; permission ask via existing camera grant.
5. **BodySilhouetteRenderer:** `VNGeneratePersonSegmentationRequest` (.accurate) on the captured image → CoreImage blend: ink `#2A1F1E` figure on paper `#FCFAF7`; `poseQuality` = confident-joint fraction at capture. Graceful empty-mask (plain paper, quality 0).
6. **BodyScanFlowView (the craft):** consent (first run: "your record, private." + three truth lines + silhouette/photo choice, silhouette pre-selected, clinical register) → capture (full-bleed mirrored preview; ghost overlay of last silhouette at 12%; ONE serif coaching line; 3·2·1 countdown w/ tick haptics on armed; freeze + swell on capture; quiet "capture now" fallback after 8s or `--uitest-scan-allow-manual`) → landed (result draws in on paper, dateline, "keep it" / "retake") → record (latest scan + count line + "scan again" + prior strip). Cover case `.bodyScan` + host dispatch + QA door `--uitest-open-body-scan`.
7. **Truth + retire:** camera usage string gains the Body Vision clause (D10 draft); `PlankApp/Camera/CameraManager.swift` deleted (pose stack salvaged into #4) with its 4 pbxproj entries.
8. **Verify:** build + full suite (421 + ~15 new); `BodyScanProofUITests` (QA doors: consent → manual capture → keep → relaunch → record persists); recorded capture-flow video, frame-reviewed; screenshots to founder. Real-pose guidance = founder device walk (sim shows no person; noted in record).
