# Legal drafts — COUNSEL REQUIRED

Everything in this folder is a **non-binding working draft** to make a
lawyer's job faster and cheaper. None of it is legal advice, none of it
is executed, and none of it may be presented to a clinic as final.

Before any real-clinic, real-data pilot, counsel must review and
finalize:
- `PILOT_AGREEMENT.md` — the bounded pilot terms (needs a BAA exhibit).
- `SECURITY_STATEMENT.md` — the honest posture (no HIPAA-compliant claim).
- `PATIENT_NOTICE.md` — what the connected patient is told (maps to the
  in-app consent screen; must match the BAA).
- Consumer privacy-policy delta for the care platform (not drafted here;
  the existing `docs/privacy_policy.md` predates the clinic layer).

The BAA itself is not drafted here — start from the clinic's template
or HHS's sample business-associate provisions, with counsel.
