# 03 — Information architecture

## Tabs: three, plus nothing

```
today        jeni        becoming
```

Custom `JKTabBar` (no native TabView chrome): cream bar, 0.33pt
hairline top rule, three lowercase DMSans labels; the active label
swaps to JeniHeroSerif-Italic with a 3pt cocoa dot beneath
(matchedGeometry between tabs), soft haptic on switch, content
cross-fades via the existing bloom. No icons in the bar — the
editorial move; labels are the icons. (Reduce-motion: dot teleports.)

Rationale: founder memory locks "tabs reserved for program surfaces,
grow today/becoming → +jeni." The camera FAB dies — it overlapped
content, hid pre-enrollment, and is one tap from Today anyway. Snap
entry points: the plan's snap beat, the persistent camera mark in
Today's masthead, the plates strip [+], the journal, and a Jeni tool
call. The center-FAB pattern is Cal AI's grammar, not ours.

## Surface map

**today** — the ritual (04_DAILY_PROGRAM.md):
masthead (day pill · date · camera mark · menu mark) → jeni's brief
line → day strip → today's beats (3-5 plan rows) → living state band
(protein arc · kcal line · steps ring · plates filmstrip) → evening
close (after 18:00) / tomorrow whisper. Pre-enrollment state = the
program onramp rebuilt in v2 language (one screen, hold-to-begin).

**jeni** — the chat (05_CHAT.md):
transcript (editorial letter register, not bubbles) → composer →
suggestion chips seeded by state. Day brief lands as jeni's first
message each day. Tool-call action cards render inline.

**becoming** — the payoff (08 curation of existing atoms):
diary hero (day N · shown up N times) → weight trend canvas (hero) →
this-week row (dots + archetype letters) → food story (protein
week-view + plates) → her wins (deeds + NSV echo + insight line).
Five modules maximum. Depth sheet keeps the long tail.

## Navigation model

- Each tab hosts a `NavigationStack` (finally) with a shared
  `JKRoute` enum; sheets reserved for *actions* (log weight, mark
  done, share), covers for *immersions* (workout, breath, lesson,
  snap camera, chat thread is a tab so never a cover).
- One `AppRouter` (@Observable) owns tab selection + pending deep
  links. Notification taps and Jeni tool calls route through it:
  `jenifit://today`, `://snap`, `://jeni?seed=...`, `://lesson/{id}`,
  `://breath/{style}`, `://weigh-in`, `://trend`.
- Settings: quiet `line.3.horizontal` mark in the Today masthead
  (top-right) AND becoming's masthead — the audit's "unreachable from
  Becoming" fix. Presents ProfileHub as a sheet (existing, reskinned
  chrome only).

## Module entry/exit grammar (kills the dead-ends)

Every module cover gets the same close: completion → module's own
celebration (kept) → **the chain line**: one quiet suggestion row
("next: 60 seconds of breath" / "tomorrow: your movement day") that
either deep-links or dismisses to Today with the completed row
striking through *on screen* (the cross-off is the shared gesture
language from onboarding — completion animates the strike + soft
tick cascade, same as OV5SelectRow).
