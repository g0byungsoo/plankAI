# 19 — v2.5: the one-go overhaul plan

Date: 2026-07-03. The thesis (16) applied across the app in one
sprint. Rule: every item below is BUILT this session; deferrals must
name a gate, not a vibe.

## The unifying mechanic: everything chains

v2.4 proved the pattern on lessons. v2.5 makes "the next right
action" a system property:
- workout completes → "protein within a couple hours keeps the
  build" → snap
- plates land → protein-aware next ("dinner idea?" → jeni seeded)
- weigh-in saves → "the trend line does the thinking" → becoming
- lesson completes → breath (v2.4)
Chains are one-shot, quiet, dismissible — coaching, not nagging.

## Build list (per feature, all this session)

1. **Brief engine** — steps thread joins the cascade (yesterday's
   goal-hit becomes today's easiest-lever line); chains carry chat
   seeds.
2. **Jeni chat** — suggestion chips become STATE-AWARE (computed
   from the live snapshot: protein gap by evening, trend uptick,
   comeback, craving hour) so the empty composer always offers the
   conversation she actually needs.
3. **Journal/reflection v1** — the evening close gains "one line for
   her file": a lesson-aware guided prompt (never an essay; one
   optional line, stored by dayKey, joins the feeling tap).
4. **Food log** — day headers become protein-first receipts ("84g
   protein · 3 plates · about 1,420 cal") — the day reads as a
   pattern, not a sum.
5. **Snap lifecycle** — post-log chain with a protein-aware jeni
   seed (the result carousel stays; the AFTER now coaches).
6. **Weight** — post-save chain interprets instead of judging.
7. **Steps** — the brief thread (above) + already-shipped sheet =
   the easiest-lever framing everywhere it appears.
8. **Workouts** — completion chains into protein; floor + voice
   shipped in v2.4.
9. **Becoming** — Sunday gains the weekly receipt block (the week,
   kept — from real WeekState numbers); fresh users get a designed
   not-enrolled state instead of hidden sections.
10. **Notifications** — the daily anchor finally speaks the brief's
    voice: rescheduled on each Today refresh with TOMORROW's
    archetype line at her hour (one id, surgical replace — push and
    app never diverge).
11. **Breathwork** — v2.4 reframe verified in the ledger re-run.
12. **Empty/loading/error** — becoming not-enrolled state; chat
    failure lines already designed; no skeletons ever (anti-slop).
