# Onboarding v5 — Strategy (synthesis of the 7-lens panel)

2026-07-02. Panel raw output: `PANEL.md`. Flow spec: `FLOW.md`.

## The one-line thesis

v4.5 TELLS value for 53 screens; v5 SHOWS it — one product-magic beat
(snap demo), one visible computation (receipt-tape build + causal
receipts), one tactile input language (cross-off + rulers), and a
terminal run that ascends into the wall with zero admin — while keeping
every gram of v4.5's conversion science and data contract.

## The ten decisions (each traces to ≥3 panel lenses)

1. **Cross-off is THE select.** Single-selects: tap → chosen radio fills
   cocoa, unselected rows draw a 1.5pt strikethrough left-to-right
   (180ms, 40ms stagger, soft haptic ticks, dim to 38%) → auto-advance
   ~0.45s. Continue survives only on multi-select, rulers, text, and
   the sensitive cluster (GLP-1 / medication / hormonal — deliberateness
   reads as respect). Kills ~25 taps + the 1.2s feedback dwell tax.
2. **Snap demo mid-food-wedge, staged as the flow's single luminance
   inversion.** Cream → she picks 1 of 3 real-looking plates → photo
   expands full-bleed (matched geometry) → REAL Metal `snapSweep` pass →
   plate card with count-up kcal + protein (the exact product register,
   ± range honesty) → permission line "it *fits*. no drama either way."
   → exits into a Day-1 prefill ("tomorrow: snap your first real meal").
   Honest theater: "one of our plates, so you can *feel* it."
3. **GLP-1 status moves to the top of Act II** (path-fact, not
   confession) so the food wedge, teaches, build ritual, projection and
   first week all cohort-route. Post-GLP-1 gets a real branch (stop
   window + appetite return + regain-truth teach w/ JAMA chip); current
   gets phase + appetite rhythm + muscle-math teach; considering gets
   one agency interstitial. Kill every unshipped-feature promise in
   inline feedback (FTC floor).
4. **Vulnerability is repaid.** Reciprocity beat becomes a data-mirror
   ("you told us the truth. here's what it *changes*." + 3 rows citing
   her stored answers). Confirmations only on the ~5 costly disclosures.
   Prior attempts rephrased "how many times have you *started over*?".
5. **The care part is a named chapter, not scattered forms.** Medication
   Q + SafetyGate (SCOFF/pregnancy/BMI) relocate to the end of Act III
   as "a few questions we ask *every* woman." — diagnostic rigor slot,
   warm-handoff terminals, gate machinery untouched, still pre-paywall
   (earlier, in fact). Frees the goal→reframe conveyor AND un-buries the
   reveal climax.
6. **The terminal run ascends.** Kill pre-wall ratingAsk (post-purchase
   owns rating). Disclaimer folds into the consent signature moment
   (same keys). Reveal = hold-to-build → receipt tape (REAL answers —
   fixes the v4.5 dead-field narration bug) → pace → projection →
   day-one contract → fear-resolution beat (replaces ratingAsk slot) →
   commitment (single merged time anchor) → nudge ask (+ trial-reminder
   promise reading the live intro offer) → wall.
7. **Projection carries causal receipts** ("because you sleep under six
   → we paced you gentler"), a protein co-line (flip
   `protein_hero_enabled`, GLP-1 cohorts get it accented), the HK steps
   payoff line, cohort named plainly, and the identity bookend greeting
   ("maya, the *calm* one. she's already in you."). Emoji-heart bug →
   typographic ♥.
8. **Nine screen archetypes, never two identical in a row**, 3-band
   vertical rhythm, 5 hairline act segments + lowercase act eyebrow,
   progress frozen across micro-runs. Act boundaries are RECEIPTS
   (her answers mirrored back), never timed dwells.
9. **Name in Act I.** Everything downstream is addressed to her
   (dossier, loader, projection, wall's namePrefix stops rendering
   empty).
10. **Felt tactility everywhere**: tick rulers for age/height/weight/
    goal (haptic detents, digit-roll pill, live derived line, delta
    band, BMI-floor gate), fears as rapid-fire giant-serif statements
    with strike-the-fear, hold-to-build gesture, day-one artifact card.

## Explicit conflict resolutions

- **Aura gradient cards** (genz) vs **gradient ban** (designer): BAN
  wins — locked tokens + founder's no-generic-gradients. Stress renders
  in the statement family instead.
- **Option stickers on food-relationship** (v4.5) vs kill (psych):
  killed. Typography carries disclosure screens.
- **"Make it official" share composer pre-wall** (genz): scoped to the
  day-one artifact card + a single share button (ImageRenderer → share
  sheet). No composer UI pre-wall; full composer stays a post-purchase
  follow-up.
- **Tier ladder as mood-board strips** (genz): deferred — pace picking
  already owns tiers in the reveal; case 260's slot becomes the Act IV
  receipt. No duplicate pace surface (T5 rule).

## What we deliberately do NOT change

Paywall internals; PostPurchaseFlow; program engine math; sync;
SafetyGate routing logic; pace-before-projection order; the founder's
five loved reveal screens' register (re-skin only); anonymous-first (no
pre-wall sign-in); all AppStorage keys (DATA_CONTRACT.md).
