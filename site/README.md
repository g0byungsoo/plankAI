# Jeni Care — public clinician site

Static, self-contained (system fonts; the only network call is the
pilot-request RPC). Deployed to Vercel; no custom domain this pass.

- `index.html` · `styles.css` · `main.js`
- `config.js` — the Supabase URL + publishable key the pilot form
  POSTs to (`care_submit_pilot_request`). Replace at deploy time for a
  pilot environment; never put a service key here.
- `assets/shots/` — REAL dashboard captures, regenerated by
  `clinic/e2e/capture.spec.ts` (CAPTURE=1) against a disposable local
  stack seeded with fictional data, leak-checked before every shot.

Local preview: `python3 -m http.server` in this directory.
Regenerate evidence: see `docs/app_v8/pilot/RUNBOOK.md` → "product evidence".
